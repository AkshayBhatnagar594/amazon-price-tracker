Connect a GitHub token

This page has no backend, so triggering checks, adding products, and setting alert thresholds needs a token your browser can use to call GitHub's API directly. It's stored only in this browser (localStorage) — never sent anywhere else.

  1. Go to github.com → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Under "Repository access", choose Only select repositories → this repo
  3. Under "Permissions" → "Repository permissions", set Actions to Read and write (nothing else is needed)
  4. Generate, copy the token, and paste it below
